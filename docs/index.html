Your expenses.

A small self-hosted expense manager that organizes spending by group and tag.

Features

Everything you need, nothing you don't

Simple tracking that works the way you think about money.

Groups

Keep trips, household and projects separate, each with its own running total.

Tags

Slice spending across groups with tags like food, travel or rent.

Notes

Attach context to any expense so you remember what it was for.

Infinite scroll

Browse a long history by month without paging.

Installable PWA

Add it to your phone's home screen; the app shell is cached.

You own the data

Runs on your machine with your PostgreSQL. Signup can be switched off.

Screenshots

On the desktop

Click any screenshot to enlarge it.

Mobile

And in your pocket

Install it to your home screen and log expenses in a few taps.

Self-host

Run it in minutes

Bring your own PostgreSQL, then start both services with Docker. 

git clone https://github.com/thameemk/billbo
cd billbo
cp backend/.env.example backend/.env   # set DATABASE_URL
cp web/.env.example web/.env
docker compose up --build
